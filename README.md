## Project Title
BMI Calculator

## Description
This is a command-line BMI Calculator developed in Python. The program takes a person's height and weight, calculates BMI, and displays the corresponding BMI category.

The project also supports multiple records and provides basic statistics such as the lowest BMI, highest BMI, and average BMI.

## Features
- Calculate BMI using weight and height
- Metric input: kilograms (kg) and centimetres (cm)
- Imperial input: pounds (lb) and feet/inches
- BMI category classification
- Healthy weight range calculation
- Input validation for incorrect values
- Store multiple people's records
- View all saved records
- Display BMI statistics
- Uses Python functions, loops, conditional statements, lists and dictionaries

## BMI Formula

BMI = Weight (kg) / Height (m)^2

## BMI Categories
- Below 18.5: Underweight
- 18.5 to 24.9: Normal weight
- 25.0 to 29.9: Overweight
- 30.0 and above: Obese

## Requirements
- Python 3.x
- No external Python libraries are required.

## How to Run

1. Save the Python program as:

   bmi_calculator.py

2. Open the terminal in the project folder.

3. Run:

   python bmi_calculator.py

4. Select an option from the menu and enter the required details.

## Menu Options

1. Add Person
2. View All Records
3. Statistics
4. Exit

## Example

Input:

The program calculates the BMI and displays the BMI category.
